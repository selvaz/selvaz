### LazyBridge

Open-source Python framework where **Claude Code, Codex and API models work as one agent team**.

- **[LazyBridge](https://github.com/selvaz/LazyBridge)** — the framework · [lazybridge.com](https://lazybridge.com) · `pip install lazybridge`
- **[LazyTools](https://github.com/selvaz/LazyTools)** — tools, MCP server, quota-aware routing
- **[LazyPulse](https://github.com/selvaz/LazyPulse)** — always-on agents, timers, Telegram
- **[LazyCrawler](https://github.com/selvaz/LazyCrawler)** — web search and crawl for agents

Other public repositories are personal finance research built on LazyBridge (proprietary).

Updates: [@LazyBridgeLabs](https://x.com/LazyBridgeLabs)
